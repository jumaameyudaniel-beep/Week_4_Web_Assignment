# SpendWise Dashboard Shell

## Project Overview

SpendWise is a modern personal finance dashboard shell designed to provide users with a clear overview of their income, expenses, savings, and spending categories.

This project focuses on creating the visual foundation of the dashboard using HTML and modern CSS techniques. It uses realistic static financial information and does not include JavaScript functionality.

## Features

- Responsive dashboard layout
- Sidebar navigation menu
- Dashboard header
- Financial summary cards
- Six spending category cards
- CSS Grid for page and card layouts
- Flexbox for internal component layouts
- CSS custom properties for the color theme
- Hover and keyboard focus micro-interactions
- Responsive design below 768px
- Dark theme using `prefers-color-scheme`
